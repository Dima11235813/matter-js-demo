# Research

Source-grounded investigations that drive plans in [`proj-mgmt/`](../proj-mgmt/). Each report states its question, method, measured findings, and recommendation; experiments are reproducible and kept out of the unit test suite.

| Report | Drives | Reproduce |
|---|---|---|

| [Embedding shape](embedding-shape.md): why 3D layouts settled into a sphere; rank-based shapes (lines, rings), then the grouped model that separates clusters after player feedback | Epic 5 · Features 5.14–5.15 (MVP shipped) | `yarn research:cross-dim` |
| [Analogy scoring](analogy-scoring.md): whether "reward answers that connect to the third word, penalize ones that connect to the first or second" is fair and hard to game; the literal rule is inverted; held-out validation shows vectors alone cannot score fairly; timed rounds instead score designed questions (dealt analogy quads), validated by simulating player strategies | Epic 2 · Feature 2.11 | `npx vitest run --config docs/research/experiments/vitest.research.config.ts analogyScoring quadBoards` |
| [Letters merge rules](letters-merge-rules.md): why sprinkled letters formed fragments (the any-substring rule, not the dictionary); prefix-only rules from the vocabulary form 2.5× the real words, and they carry into Discovery | Epic 4 · Task 4.5.10, Epic 2 · Feature 2.14 | `node docs/research/experiments/browser/lettersMergeRules.probe.mjs` (dev server running) |
